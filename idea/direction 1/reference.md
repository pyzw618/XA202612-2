# 听起来很高大上的跨学科概念
- 认知失调理论（费斯汀格）

**核心**：人会主动修正自身行为与自我偏好的矛盾，当外在选择和内心固有偏好冲突时，会下意识修改主观偏好完成自洽。
**答辩亮点**：区别于简单关键词抓取偏好，Agent 不能只采信用户单次指令；单次反常指令属于**情境性失调行为**，需加权长期历史行为锚定真实稳定偏好。
**工程落地**：偏好库区分「瞬时临时偏好」「核心稳态偏好」，对违背历史高频偏好的单次输入降权重。

- 锚定效应（卡尼曼 行为经济学）

**核心**：人类决策会被最早接触的信息锚定，初始交互会永久塑造后续偏好基线。
**答辩话术**：本 Agent 引入**首轮交互偏好锚定模块**，将用户首次交互意图作为偏好初始锚点，后续迭代基于锚点微调而非完全覆写，解决小样本冷启动偏好提取难题。
