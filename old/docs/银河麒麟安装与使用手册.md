# Kylin MemoryHub 安装与使用手册

本文面向希望在银河麒麟桌面操作系统 V11 上体验 MemoryHub 的用户。当前安装包为 **Kylin MemoryHub 0.1.0-12（amd64）**，适用于 `x86_64/amd64` 设备。

## 1. 下载

1. 打开项目的 [GitHub Releases](https://github.com/pyzw618/XA202612-2/releases) 页面。
2. 进入最新的 Kylin Release。
3. 下载以下两个文件：
   - `kylin-memoryhub_0.1.0-12_amd64.deb`
   - `kylin-memoryhub_0.1.0-12_amd64.deb.sha256`

如果后续发布了更高版本，请下载文件名中版本号最大的 `amd64.deb` 和对应的 `.sha256` 文件。

## 2. 校验安装包

在下载目录打开终端，执行：

```bash
cd ~/Downloads
sha256sum -c kylin-memoryhub_0.1.0-12_amd64.deb.sha256
```

终端显示 `成功` 或 `OK` 后再继续安装。若校验失败，请删除文件并重新下载。

## 3. 图形化安装（推荐）

安装前请确认：

- 系统右下角没有红色的“维护模式”提示。如果处于维护模式，请先保存更改并退出维护模式，重启进入正常模式。
- 对于未使用麒麟开发证书签名的体验版，请打开“设置 → 安全中心 → 安全工具 → 应用程序来源检查”，临时选择“关闭”。

然后按以下步骤操作：

1. 在文件管理器中双击 `.deb` 文件。
2. 在系统安装器中点击“安装”。
3. 按提示输入当前用户密码并等待安装完成。
4. 安装成功后，将“应用程序来源检查”恢复为“警告”。
5. 注销并重新登录一次，让 MemoryHub 完成当前用户配置和 OpenCode 插件配置。

> 如果安装器提示“系统中已经存在同名软件包”，说明相同版本已经安装，无需重复安装。需要重新安装时，可先按本文“卸载与重装”一节卸载。

## 4. 命令行备用安装

图形安装器不可用时，银河麒麟 V11 不可变系统应通过 KARE 安装到 `shadow`
运行环境。在 `.deb` 文件所在目录执行：

```bash
sudo kare -e shadow -i ./kylin-memoryhub_0.1.0-12_amd64.deb
```

不要使用 `sudo apt install` 或 `sudo dpkg -i` 直接写入宿主基础层；系统的
`ostree-pkgs-guard` 会阻止此类操作。安装完成后注销并重新登录一次，用户配置和
OpenCode 插件配置会自动完成。

如需手动重新执行用户配置，请通过 KARE 运行：

```bash
kare run --redirect_io kylin-memoryhub /usr/bin/memoryhub-configure-opencode --current-user
```

## 5. 首次启动与检查

从应用菜单搜索并打开 **MemoryHub**。控制台左下角显示“后端已连接”即表示运行正常。

也可以在终端执行：

```bash
kare -l | grep -F kylin-memoryhub
kare run --redirect_io kylin-memoryhub /usr/bin/memoryhub status
```

正常情况下应看到：

- `kare -l` 显示 `kylin-memoryhub`、正确版本号和 `shadow` 运行环境；
- 状态命令能返回服务、存储、检索和安全状态。

> 银河麒麟 V11 的图形安装器会把应用安装到 KARE 隔离环境。`dpkg-query` 或
> `dpkg -s` 只读取宿主基础层，可能仍显示旧版本或 `deinstall ok config-files`，
> 不能用来判断 KARE 中的 MemoryHub 是否安装成功。

## 6. 简单体验

写入一条偏好记忆：

```bash
kare run --redirect_io kylin-memoryhub /usr/bin/memoryhub remember \
  "我偏好所有技术指导都按一步一确认的方式进行" \
  --type preference --confidence 0.9
```

检索刚才的记忆：

```bash
kare run --redirect_io kylin-memoryhub /usr/bin/memoryhub \
  search "技术指导方式"
```

也可以在 MemoryHub 桌面控制台的“偏好记忆”和“检索测试”页面查看结果。

## 7. 在 OpenCode 中使用

本安装包会自动把 MemoryHub 插件、命令、工具和技能配置到当前用户的 `~/.config/opencode/` 目录。MemoryHub、CLI、MCP 和 OpenCode 默认都使用实际登录的 Linux 用户；控制台左下角可在“当前用户”和 `global` 全局用户之间切换。

如果先安装了 MemoryHub、后安装 OpenCode，可在控制台总览页点击 **一键配置**。点击右侧的 **打开 Agent** 会在家目录打开系统终端并自动启动 OpenCode。

在 OpenCode 中查看 MCP 状态，确认 `memoryhub` 显示为已连接或可用。随后可以直接要求 Agent：

```text
请记住：我偏好所有技术指导都按一步一确认的方式进行。
```

如果 OpenCode 中没有出现 MemoryHub，退出 OpenCode 后执行：

```bash
kare run --redirect_io kylin-memoryhub /usr/bin/memoryhub-configure-opencode --current-user
```

再重新启动 OpenCode。

## 8. 常见问题

### 双击后立即显示“安装失败”

先检查系统是否处于维护模式。维护模式会导致图形安装器无法正常创建安装环境；退出维护模式并重启后再试。

### 提示软件包验证失败

体验版可能未使用麒麟开发证书签名。确认 SHA256 校验通过后，临时关闭“应用程序来源检查”再安装，安装完成后恢复为“警告”。

### MemoryHub 可以启动，但 OpenCode 找不到插件

执行：

```bash
kare run --redirect_io kylin-memoryhub /usr/bin/memoryhub-configure-opencode --current-user
```

然后彻底退出并重新启动 OpenCode。

### 安装后应用菜单中暂时没有 MemoryHub

先注销并重新登录；仍未出现时，可在终端运行：

```bash
kare run kylin-memoryhub /usr/bin/memoryhub_app_launcher
```

## 9. 卸载与重装

卸载软件：

```bash
sudo kare -P kylin-memoryhub
```

该命令不会删除用户记忆数据。重新安装时再次双击 `.deb`，或运行本文的命令行安装命令即可。

用户数据默认保存在：

```text
~/.local/share/MemoryHub/
```

如需彻底清除数据，请先确认不再需要已有记忆，再手动处理该目录。
