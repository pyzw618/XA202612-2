## 2. 临时编写的后端文件

为了前端能测试，我们**在 memoryhub/ 下临时写了/重建了以下文件**，它们不是 main 正式代码：

| 文件                               | 作用                                                                                                                                                      | 备注                 |
| ---------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------- |
| `memoryhub/adapter/agent_api.py` | 临时 agent 路由`/api/agent/health`、`/api/agent/step`、`/api/agent/replay`、`/api/agent/actions/{id}/decision`、`DELETE /api/agent/preferences` | **关键临时层** |
| `memoryhub/core/processing.py`   | `EventProcessingCoordinator`：偏好/知识/事实候选分发                                                                                                    | 重建                 |
| `memoryhub/adapter/schemas.py`   | 末尾加回`EventProcessingSummary`                                                                                                                        | main 缺这个类        |
| `memoryhub/app.py`               | `include_router(agent_router)` + 挂 `app.state.event_processor`                                                                                       | 只加了几行挂载       |

**如果你之后要迁回 main 正式方案（MCP/插件），前端 `controller.py` 里所有 `/api/agent/*` 调用都要跟着改。** 临时适配层接口路径与返回结构**严格对应用前端现有代码**，改前先看 `memoryhub_qml/controller.py`。

**临时适配层几个已知设计点：**

- `llm_client=None`：不依赖 LLM，结构化偏好/知识/事实走确定性数据（避免 ollama 未跑时 step 阻塞 4s+）
- 事实候选存后端**进程内**（`_FACT_PENDING`），**重启后端即丢失**，演示可接受
- `source_type` 归一化：旧演示数据 `chat`→`user_behavior`
- 偏好 memory_id 无时自动 `_{idx+1}` 唯一化，避免同轮多条偏好互相覆盖
- **清空偏好会同时清空整个向量库**（避免检索返回已删除的幽灵记忆）

## 3. 前端架构

```
memoryhub_qml/
├── __main__.py        # 入口 (python -m memoryhub_qml)
├── api.py             # 网络层：GET/POST/DELETE，统一信号
├── controller.py      # 核心：所有页面加载/操作/响应解析（_on_success 已加异常防护）
├── models.py          # DictListModel 及各页面数据模型
├── replay.py          # 演示 JSON 加载/脱敏/会话刷新
└── qml/
    ├── Main.qml       # 主界面：左侧菜单 + StackLayout 按 sectionIndex 分发
    └── components/    # 11 个页面 View + FactDialog + 卡片
```

console文件夹为老前端，已废弃，但可参考功能；
frontend为网页演示版本，未废弃但很久未更新。

## 4. 接口契约（前端依赖）

### A. 临时适配层 `/api/agent/*`

| 接口                                       | 用途                 | 前端用到字段                                                                                           |
| ------------------------------------------ | -------------------- | ------------------------------------------------------------------------------------------------------ |
| `GET /api/agent/health`                  | 探测在线             | `{"status":"ok"}`                                                                                    |
| `POST /api/agent/step`                   | 逐轮执行             | `processing`/`candidate_memories`/`fact_proposals`/`tool_calls`/`write_summary`/`warnings` |
| `POST /api/agent/replay`                 | 回放                 | `events`/`processing`/`written_event_ids`                                                        |
| `POST /api/agent/actions/{id}/decision`  | 事实裁决             | `status`/`requires_decision`                                                                       |
| `DELETE /api/agent/preferences?user_id=` | 清空偏好（含向量库） | `deleted`                                                                                            |

### B. main 原生 `/api/memory/*`

| 页面     | 接口                                                                        |
| -------- | --------------------------------------------------------------------------- |
| 偏好     | `GET /api/memory/preferences`                                             |
| 知识     | `GET /api/memory/knowledge`                                               |
| 事实     | `GET /api/memory/facts`                                                   |
| 检索     | `POST /api/memory/search`                                                 |
| 冲突     | `GET /api/memory/conflicts` + `POST /api/memory/conflicts/{id}/resolve` |
| 遗忘     | `GET /api/memory/forget/history` + `POST /api/memory/forget`            |
| 安全     | `GET /api/memory/safety/user-rules`                                       |
| 评测     | `GET /api/memory/evaluate/reports`                                        |
| 接入记录 | `GET /api/memory/extraction/tasks`                                        |

## 5. 当前 Bug / 已知问题

### ❗ 未解决的

1. **事实记忆页在执行前仍有一条莫名的事实**：检索页"没执行前不显示内容了"已修好（清空向量库），但**事实记忆页还是会冒出一条不存在的记忆**。现象是：还没执行任何轮次，facts 页有一条"李明"相关的事实。
2. **设置页面文字重叠**：设置页（`SettingsView.qml`）排版仍有重叠。已试过给卡片设 `implicitHeight` 但仍重叠，**需要继续调 QML 布局**（可能是 ScrollView 内 ColumnLayout + 卡片 anchors 的问题）。这个是纯前端 UI 问题。

### 📌 后端限制（不是前端 bug，先确认再改）

3. **安全规则页面**：`GET /api/memory/safety/user-rules` 裸跑 uvicorn 会返回 `{"code":"user_rule.invalid_request"}`。**main 的这个接口依赖身份解析器（identity header），裸跑没注入就报错**。页面会显示"请求失败"是后端限制，不是前端问题。若演示需要它可用，得后端注入身份解析器（或前端做降级提示）。
4. **遗忘接口中文不分词**：`POST /api/memory/forget` 对中文指令几乎返回 `deleted_count=0`（后端分词问题）。前端已接通但删不到记忆，别当前端 bug。
5. **检索无相关度阈值**：`POST /api/memory/search` 低分也会返回。前端没做过滤。
6. **评测是 stub**：`GET /api/memory/evaluate/reports` 基本空。
