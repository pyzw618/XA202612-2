# MemoryHub 前端毛玻璃侧边栏技术报告

> 项目：Kylin-MemoryHub 桌面客户端（Qt 5.15 Widgets）
> 目标环境：银河麒麟 V11（UKUI 4.x，wlcom Wayland 合成器）
> 日期：2026-08-13

---

## 1. 背景与目标

MemoryHub 桌面客户端的左侧导航栏原为纯色背景（`#F7F9FC`）。需求是：

- 让左侧导航栏呈现麒麟系统原生的**透明磨砂玻璃（毛玻璃）效果**——半透明 + 背景模糊；
- 不引入重量级第三方框架，使用 UKUI 平台自带的原生能力，保证系统兼容性。

---

## 2. 实现原理：UKUI 原生毛玻璃机制链

调研了 `前端重构/代码仓库分析/` 中拉取的 `qt5-ukui-platformtheme` 源码，并反汇编了系统实际安装的
`libqt5-style-ukui.so`（4.20.1.0）与 `libkysdk-ukuiwindowhelper.so.1`，确认完整链路为：

```
Qt 窗口 (WA_TranslucentBackground)
  │  QStyle::polish() 时被注册
  ▼
ukui 样式插件内的 BlurHelper（libqt5-style-ukui.so）
  │  窗口 UpdateRequest/LayoutRequest 事件时读取窗口属性 "blurRegion" (QRegion)
  ▼
UkuiWindowHelper::setBlurEffect(region, strength, enable)（libkysdk-ukuiwindowhelper.so）
  │  Wayland 分支（platformName == "wayland"）
  ▼
UkuiDisplay → ukui_blur_manager_v1 / ukui_blur_surface_v1 协议
  ▼
wlcom 合成器（kylin-wlcom）对指定区域做 GPU 模糊渲染
```

几个关键事实（通过源码 + 反汇编确认）：

1. **`qt5-ukui-platformtheme` 的 ukui 样式内置 `BlurHelper`**：`ProxyStyle::polish(QWidget*)`
   会把所有“顶层窗口 + `Qt::WA_TranslucentBackground`”的控件注册给 `BlurHelper`。
   注册时读两个自定义属性：
   - `useSystemStyleBlur = true` → 允许系统模糊（`shouldSkip` 逻辑）；
   - `doNotBlur = true` → 明确拒绝模糊。
2. **模糊范围由 `blurRegion` 属性决定**：`BlurHelper::delayUpdate()` 在窗口重绘时读取
   `widget->property("blurRegion")`（类型 `QRegion`），传给合成器，只模糊该区域。
3. **wlcom 双协议支持**：`/usr/bin/kylin-wlcom` 同时实现 `org_kde_kwin_blur_manager_v1`
   （KDE 协议）与 `ukui_blur_manager_v1`（UKUI 原生协议），以及 X11 的
   `_KDE_NET_WM_BLUR_BEHIND_REGION` 原子。安装版 ukui 样式走 UKUI 协议。
4. 官方主题参数（`theme.conf` 的 `[effect]` 段）：`transparencyBlur=65`，
   即毛玻璃窗口透明度约 65%。

因此应用侧**零额外依赖、零手写协议代码**，只需满足样式的属性契约即可。

## 4. 各文件具体改动

### 4.1 `desktop-client/src/MainWindow.h`

新增三个声明，供模糊区域管理与窗口缩放同步：

```cpp
protected:
    void resizeEvent(QResizeEvent *e) override;   // 窗口缩放时重新上报模糊区域

private:
    ...
    void updateBlurRegion();                      // 计算并上报侧边栏模糊区域
    ...
    QWidget *m_sidebar = nullptr;                 // 侧边栏引用（计算区域用）
```

### 4.2 `desktop-client/src/MainWindow.cpp`

**(1) 构造函数开头——开启透明 + 声明允许系统模糊（第 151–155 行）：**

```cpp
// UKUI 原生毛玻璃：开启窗口透明，由 ukui 样式 + 合成器对侧边栏区域做背景模糊。
// 通过 blurRegion 属性限定模糊范围（见 updateBlurRegion()）。
setAttribute(Qt::WA_TranslucentBackground, true);
setProperty("useSystemStyleBlur", true);
setProperty("doNotBlur", false);
```

- `WA_TranslucentBackground`：窗口表面透明，否则合成器没有可模糊的“透出内容”；
- `useSystemStyleBlur=true`：让 ukui 样式的 `BlurHelper` 把本窗口登记为模糊对象
  （否则 `shouldSkip()` 会跳过普通窗口，只对 QMenu/QTipLabel 生效）；
- 该属性必须在窗口被样式 `polish()` 前设置，因此放在构造函数最早位置。

**(2) 记录侧边栏引用（第 166 行）：**

```cpp
auto *sidebar = new QWidget(central);
m_sidebar = sidebar;
sidebar->setObjectName("sidebar");
```

**(3) 右栏设置对象名（第 281 行）——QSS 定位用：**

```cpp
auto *right = new QWidget(central);
right->setObjectName("rightPane");
```

**(4) 新增 `updateBlurRegion()` 与 `resizeEvent()`（构造函数末尾调用，约第 403–417 行）：**

```cpp
void MainWindow::updateBlurRegion() {
    if (!m_sidebar) return;
    // 窗口坐标下的侧边栏区域（供 ukui 样式的 BlurHelper 设置合成器模糊范围）
    const QPoint origin = m_sidebar->mapTo(this, QPoint(0, 0));
    setProperty("blurRegion", QVariant::fromValue(QRegion(QRect(origin, m_sidebar->size()))));
    update();   // 触发 UpdateRequest → BlurHelper 把区域上报给合成器
}

void MainWindow::resizeEvent(QResizeEvent *e) {
    QMainWindow::resizeEvent(e);
    updateBlurRegion();
}
```

要点：

- `mapTo(this, ...)` 把侧边栏几何换算成**窗口本地坐标**（wlcom 模糊区域使用 surface 本地坐标）；
- `blurRegion` 属性保存 `QRegion`（Qt 内置元类型，可直接 `QVariant::fromValue`）；
- `resizeEvent` 保证窗口缩放/最大化后模糊区域跟随侧边栏；
- 构造函数末尾先调一次，窗口首次显示时区域已就绪。

新增头文件：`#include <QRegion>`、`#include <QResizeEvent>`、`#include <QVariant>`。

### 4.3 `desktop-client/resources/style/kylin.qss`

**(1) 窗口与中央容器透明化（第 5 行）：**

```css
QMainWindow, QWidget#centralRoot { background: transparent; }
```

原因：侧边栏是 `centralRoot` 的子控件。若中央容器继续涂不透明底色，侧边栏半透明背景只能
混合到容器的实色上，桌面内容永远透不出来。

**(2) 右栏保持不透明（第 6 行）：**

```css
QWidget#rightPane, QWidget#dashboardBody, QScrollArea#dashboardScroll { background: #F3F6FA; }
```

右侧内容区（顶栏 + 页面栈）必须不透明，否则整个窗口都会透视桌面。

**(3) 侧边栏半透明 + 弱化边框（第 9 行）：**

```css
QWidget#sidebar { background: rgba(246, 248, 252, 0.52); border-right: 1px solid rgba(180, 192, 208, 0.35); }
```

- 透明度取 `0.52`（参考官方 `transparencyBlur=65` 约 0.65，可再调）；
- 边框同步半透明化，避免实色描边破坏玻璃质感。

## 5. 为什么这样能生效（时序）

```
构造 MainWindow
  ├─ setAttribute(WA_TranslucentBackground)      ← polish 前
  ├─ setProperty(useSystemStyleBlur/doNotBlur)   ← polish 前
  └─ updateBlurRegion() → blurRegion 属性就绪
w.show()
  ├─ ukui 样式 polish(窗口) → BlurHelper.registerWidget(窗口)
  └─ UpdateRequest → BlurHelper.delayUpdate()
       读取 blurRegion(QRegion=侧边栏矩形)
       → UkuiWindowHelper::setBlurEffect(region, 0, true)
       → ukui_blur_manager_v1 → wlcom GPU 模糊
```

缩放窗口时 `resizeEvent → updateBlurRegion() → update()` 重新上报。

## 6. 验证方法

- 功能验证：启动客户端，侧边栏呈现半透明磨砂效果；拖拽窗口、缩放窗口后效果跟随。
- 像素级验证：用 `kylin-screenshot full` 截图，对侧边栏区域做高频能量（Laplacian 方差）
  分析，与未遮挡的桌面区域对比，确认模糊层在合成器中真实生效。

## 7. 注意事项与调参

1. **透明度**：`rgba(246, 248, 252, 0.52)` 的 0.52 可随喜好调整——值越小桌面内容越明显、
   文字对比度越低；建议范围 0.45–0.70。
2. **模糊强度**：ukui 样式上报的 strength 参数为 0（默认档），如需更强模糊需修改
   `libkysdk-ukuiwindowhelper` 层，一般无需。
3. **系统开关**：若用户在控制面板关闭了全局毛玻璃（`org.ukui.control-center.personalise`
   的 `effect` 键），合成器将不渲染模糊，侧边栏退化为普通半透明——属系统级行为，符合原生预期。
4. **不适用 X11**：wlcom 为 Wayland 专用；若将来运行于 X11（marco 合成器），ukui 样式会走
   `_KDE_NET_WM_BLUR_BEHIND_REGION` 原子路径，代码无需改动。
5. 修改后重新编译：`cmake --build desktop-client/build-linux -j$(nproc)`。
