# 阶段文档

本项目仅维护阶段化开发文档。当前事实见仓库根目录的 [`AGENTS.md`](../AGENTS.md)。

每个阶段包含三个文件：

- `DESIGN.md`：目标、范围、设计、关键约束和验收标准。
- `TASKS.md`：可执行任务及完成状态。
- `SUMMARY.md`：阶段完成后的冻结记录，包括最终结论、验证结果和遗留问题。

阅读顺序：`AGENTS.md` → 当前阶段的 `DESIGN.md` → `TASKS.md` → 相关源码和测试。
