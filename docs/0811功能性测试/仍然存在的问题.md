# 经过修改后仍然注意到的问题
## 事实
1. memoryhub的rest api没有创建事实的接口
2. 事实记忆中LLM调用是自己实现的，置信度的计算也是靠LLM反馈，有点不合理（详见LLM_CALL_CONFIDENCE_DIFFS.md）
3. 事实记忆的谓词提取效果在一些情况下会出现严重错误。
例如再处理“隔壁老王家有两个小孩，大的是哥哥，小的是妹妹，两个孩子都爱跑步”这一问题时，老大和老二会被归结为一个实体，或者老二被识别为老大的别名，这会导致关于老二的事实因为某些信息（比如这里的性别）被判定为冲突，导致一直写不进去。（这里或许得加一个写次数上限，不然写不进去会一直尝试写）总之非常混乱。解决方法我想不出来0.0
