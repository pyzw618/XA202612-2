# MemoryHub 检索评测数据标注规范 v1.0

> 配套文档：`memoryhub_retrieval_dataset_schema_v1.json`
> 核心原则：先选目标记忆，再写查询；禁止根据当前系统返回结果反向决定 relevant IDs

---

## 1. 相关性等级定义

| 等级 | 定义 | 示例 |
|:---:|---|------|
| 0 | 无关，或因 user_id/scope/project_id/status 不匹配而不可用 | 查询"生成周报"，返回的是其他用户的周报偏好 |
| 1 | 主题相关但不能直接回答/执行当前请求 | 查询"部署到生产环境"，返回"本地开发环境部署流程" |
| 2 | 相关且可部分满足请求，或作为辅助参考有用 | 查询"快速搭建 React 项目"，返回"前端项目脚手架模板" |
| 3 | 直接相关，可完整回答或执行当前请求 | 查询"按上月方式生成月报"，返回"月度报告生成工作流" |

### 指标口径

- **Recall relevant 集合**：等级 ≥ 2
- **NDCG**：使用完整 0～3 级标注
- 即使文本完全匹配，若 owner / scope / project 不正确也必须标 0
- archived、deleted 和被新版本替代的旧版本通常标 0

---

## 2. 标注流程

1. **建立候选池**：对每条查询，从记忆库中选出目标候选 + BM25 候选 + 向量候选 + 随机负例
2. **独立标注**：两名标注者独立评分，不查看系统最终融合分数或对方评分
3. **一致性计算**：使用 weighted Cohen's Kappa
4. **分歧裁决**：分歧样本由第三人裁决
5. **记录保存**：保存两名标注者的原始评分和最终裁决评分

### 一致性目标

- weighted Cohen's Kappa ≥ 0.75
- Kappa 过低时先修订标注规范，再重新标注

---

## 3. 查询构造原则

1. 先从记忆池中选择 1～5 条真正需要召回的目标
2. 明确用户、场景、项目和期望记忆类型
3. 用自然语言重新表述需求
4. 不直接复制目标记忆的标题或全文
5. 为查询加入至少一个合理干扰项（同关键词不同主题、同主题不同 scope 等）
6. 标注难度和语言

---

## 4. 难度分类标准

| 难度 | 说明 | 示例 |
|------|------|------|
| exact | 查询包含目标记忆的关键术语或标题直接匹配 | "帮我生成周报" |
| semantic | 同义改写，不直接复制记忆原文 | "帮我总结一下这周干了什么" |
| hard-negative | 存在词面相似但语义不相关的干扰项 | "配置防火墙"，内存中有"防火墙安全培训材料" |
| cross-domain | 同一关键词出现在不同场景或项目中 | "部署"可能指向代码部署或文件部署 |
| no-answer | 索引中不存在相关知识 | "如何在 OS 上安装 Python 插件 A" |

---

## 5. 干扰项标注规则

以下类型的记忆即使内容相关也应标注为等级 0 或 1：

- **Scope 不匹配**：查询的 scene/task_type 与记忆不同
- **用户隔离**：记忆的 user_id 与查询不同
- **项目隔离**：记忆的 project_id 与查询不同
- **状态过滤**：status 为 archived / deleted / replaced 的记录
- **版本管理**：被新版本替代的旧版本
- **近似标题**：workflow 与 template 标题近似但类型不同

---

## 6. 标注记录格式

标注记录保存在 `memoryhub_retrieval_annotation_records_v1.jsonl`，每行一个 JSON：

```json
{
  "query_id": "q_dev_001",
  "annotator_1": {
    "name": "annotator_a",
    "scores": {"know_dev_001": 3, "know_dev_017": 1},
    "timestamp": "2026-08-11T10:00:00Z"
  },
  "annotator_2": {
    "name": "annotator_b",
    "scores": {"know_dev_001": 3, "know_dev_017": 2},
    "timestamp": "2026-08-11T10:30:00Z"
  },
  "adjudicator": {
    "name": "adjudicator",
    "score": 3,
    "reason": "know_dev_017 仅为相似主题但不包含可执行步骤",
    "timestamp": "2026-08-11T11:00:00Z"
  },
  "resolution": "adjudicated"
}
```
