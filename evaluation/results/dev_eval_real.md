## 5. 已知问题与建议

### 5.1 Bootstrap 95% CI
- **状态**: TODO（未实现）
- **影响**: 当前仅报告点估计，无法给出统计显著性判断。
- **建议**: 在后续版本中实现 Bootstrap 重采样 1000 次计算 95% 置信区间。

### 5.2 Mock Embedding 限制
- 当前使用 SHA256 哈希伪随机向量，无语义性，FAISS/向量路接近随机。
- Hybrid 组增益主要来自 BM25 路，不代表真实 embedding 下的绝对水平。
- **建议**: 在麒麟环境上以 `--provider kylin` 重跑。

### 5.3 数据集规模限制
- Dev 集仅 30 条查询，统计波动大，权重微调差异不具统计显著性。
- **建议**: 扩展到 300-500 条查询的 test 集后再做正式验收。

### 5.4 冷/热缓存对比
- **状态**: 部分实现。当前 Hyrid 检索器不启用独立缓存层。
- **影响**: 无法测量 result cache 和 query-vector cache 的命中率。
- **建议**: 在 P0-1 完成后启用独立缓存并记录命中率。

### 5.5 原 eval_dataset.py 格式兼容
- 当前脚本仅支持新格式（0-3 级 relevance 标注），不支持旧的 `relevant_ids` 扁平列表格式。
- 旧格式评测请使用原 `evaluation/run_retrieval_eval.py`（版本请查阅 git log）。
